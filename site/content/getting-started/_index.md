Pick the route that matches how you use launcher:

- **Command line.** [Install](install/) `kurel`, then follow the [Quickstart](quickstart/)
  to build your first application.
- **Go library.** [Install](install/#use-launcher-as-a-go-library) the module, then follow
  the [library quickstart](library-quickstart/) to run the same pipeline from your program.

[Introduction](introduction/) explains the two-config-set model both routes share, and
[Examples](examples/) lists runnable application documents.
